# Дополнительный волновой изгибающий момент — ПКПС РКО, п. 2.2.10

Веб-приложение для расчёта Mдв, Nдв (классы «М», «О», «Р», «Л»): эпюры, пошаговое решение
с подстановкой чисел, 3D-модель судна, эквивалентный брус миделя с проверкой напряжений,
отчёт в PDF и Word, сохранение проектов.

**Постоянная ссылка для всех** — см. [DEPLOY.md](DEPLOY.md) (Streamlit Community Cloud, бесплатно).

## Запуск на своём компьютере (VS Code)

1. Откройте папку проекта в VS Code (File → Open Folder).
2. Откройте терминал (Ctrl+`) и создайте окружение:

   Windows:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```
   macOS / Linux:
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   ```
3. Установите зависимости и запустите:
   ```
   pip install -r requirements.txt
   streamlit run app.py
   ```
   Браузер откроется на http://localhost:8501.

Открыть с телефона в той же Wi-Fi сети: `streamlit run app.py --server.address 0.0.0.0`,
затем в браузере телефона `http://<IP-компьютера>:8501`.

## Эквивалентный брус

1. Загрузите чертёж миделевого сечения (PDF или картинку) — он появится рядом с таблицей,
   листы PDF переключаются, чёткость регулируется.
2. Заполните таблицу связей (кнопка «Пример» показывает, как). Типы: листы горизонтальный,
   вертикальный, наклонный; полоса, тавр, уголок (по размерам стенки и пояска);
   произвольный элемент (A и i из сортамента). Размеры — мм, отстояние z — м от ОП.
3. Программа считает нулевое приближение (φ = 1): площадь, нейтральную ось z0, I0 и W.
   Галочка «I из эквивалентного бруса» в боковой панели подставляет I0 в расчёт Mдв (так требует п. 2.2.10).
4. Для прогиба и перегиба выполняются последовательные приближения с редуцированием гибких пластин
   (2.2.36–2.2.39: продольная система — φ = σкр/|σж| по 2.2.72, растянутые не редуцируются;
   поперечная — табл. 2.2.39 и ограничение 2.2.39-2; нередуцируемые полосы 0,25a ≤ 25t по 2.2.37)
   до разницы напряжений в крайних кромках ≤ 5 %.
5. Напряжения σ = Mр·z·10⁻³/I (2.2.40-1) сравниваются с допускаемыми [σ] = k·kн·ReH
   (2.2.67, табл. 2.2.68: 0,70 для «М», 0,75 для «О», «Р», «Л», 0,60 для связей с местной нагрузкой).

Mр для проверки: ±Mдв (без Mтв), экстремумы из вкладки «Расчётный момент Mр» или вручную.

Данные с чертежа программа не распознаёт сама: связи вносит расчётчик, чертёж служит подсказкой рядом.
Вырезы и обрывающиеся связи (2.2.32–2.2.34) учитываются тем, какие строки внесены в таблицу.

## Единицы

L, B, H, T, Tн — м; **V₀ — км/ч** (в интерфейсе можно м/с и узлы); I — м⁴; D — кН; моменты — кН·м;
размеры связей — мм; напряжения — МПа.

## Границы этой версии

Не реализованы: п. 2.2.11 (классы «М-СП», «М-ПР», «О-ПР»), п. 2.2.15, расчёт Mтв,
касательные напряжения (2.2.40-2), предельные моменты (2.2.76–2.2.80), редуцирование жёстких связей (2.2.79).
Расчёт справочный; соответствие Правилам подтверждает расчётчик и РКО.
