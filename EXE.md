# Программа одним файлом .exe (Windows)

Готовый `Volnovoy_moment.exe` запускается на любом компьютере с Windows 10/11 —
**без установки Python и библиотек**. Двойной щелчок → откроется чёрное окно и через
20–40 секунд браузер с программой. Закрыли чёрное окно — программа остановилась.

Exe собирает сам GitHub на своём Windows-сервере (бесплатно). Делается один раз,
дальше — после каждого обновления файлов автоматически.

## 1. Загрузить файлы на GitHub

1. https://github.com → **+** → **New repository** → имя, например `pkps-wave-moment` → **Create repository**.
2. Ссылка **uploading an existing file** → перетащите **всё содержимое** папки `pkps_wave_moment`
   (не саму папку) → **Commit changes**.
3. Проверьте, что в репозитории есть папки **`.github`** и **`.streamlit`** (имена с точкой иногда
   не перетаскиваются, особенно с Mac). Если `.github` нет:
   **Add file → Create new file**, имя `.github/workflows/build-exe.yml`, вставьте содержимое
   этого файла из архива → **Commit changes**.

## 2. Дождаться сборки

1. Вкладка **Actions** в репозитории. Там появится «Сборка exe для Windows» — жёлтый кружок, идёт сборка
   (около 10–15 минут). Если GitHub спросит — нажмите **I understand my workflows, go ahead and enable them**.
   Запустить вручную: слева выбрать сборку → **Run workflow**.
2. Зелёная галочка — готово. Красный крестик — пришлите мне скриншот или текст ошибки.
   (Сборка сама проверяет, что exe запускается и отвечает, — битый файл не выложится.)

## 3. Скачать

Щёлкните по зелёной сборке → внизу **Artifacts** → **Volnovoy_moment_Windows** → скачается zip,
внутри `Volnovoy_moment.exe` (~150–250 МБ). Этот файл можно копировать на флешку и раздавать.

## Если что-то не так

- **Windows SmartScreen: «Система Windows защитила ваш компьютер».** Файл не подписан сертификатом
  (это платная услуга). Нажмите **Подробнее → Выполнить в любом случае**.
- **Антивирус ругается.** Exe-файлы PyInstaller иногда ошибочно помечаются. Добавьте файл в исключения.
- **Первый запуск долгий** (до минуты): exe распаковывается во временную папку. Это нормально.
- **Браузер не открылся** — адрес написан в чёрном окне, обычно http://localhost:8501.
- **Брандмауэр спрашивает доступ** — можно разрешить только для частных сетей; программа работает
  только на этом компьютере (адрес localhost).

Проекты сохраняются кнопкой «Сохранить проект» в файл `.json` — как и в обычной версии.
